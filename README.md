# Больше времени — Telegram Mini App

Сервис бытовых поручений внутри Telegram: выгулять собаку, забрать посылку
с ПВЗ, купить продукты, постоять в очереди и другие мелкие дела. Один
человек публикует заказ, другой откликается — прямо в мини-приложении,
без сторонних чатов.

## Что внутри

- **Бот** (Telegraf) — команда `/start`, кнопка «Открыть приложение».
- **Backend** (Express) — REST API для заказов, проверка подписи Telegram
  (`initData`), поэтому подделать запрос от чужого имени нельзя.
- **Mini App** (public/) — чистый HTML/CSS/JS без сборки: лента открытых
  заказов, форма создания с категориями услуг, вкладка «Мои заказы».
- **Хранилище** — файл `data.json`, создаётся автоматически. Никаких
  дополнительных программ (Python, компиляторов) для этого ставить не нужно.

Категории заказов заданы в `src/routes/orders.js` (константа `CATEGORIES`) —
добавляйте свои так же, эмодзи + текст.

## 1. Получить токен бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. `/newbot` → укажите имя (например, «Больше времени») и username,
   заканчивающийся на `bot` (например, `bolshe_vremeni_bot`).
3. Скопируйте выданный токен — он понадобится в `.env`.

## 2. Установка

```bash
npm install
cp .env.example .env
```

Заполните `.env`:

```
BOT_TOKEN=токен_от_BotFather
WEBAPP_URL=https://ваш-домен  # см. пункт 3
PORT=3000
```

## 3. Публичный HTTPS-адрес для Mini App

Telegram открывает Mini App только по HTTPS-адресу. Варианты:

**Для быстрого теста (локально):**

```bash
npx ngrok http 3000
```

Скопируйте выданный `https://...ngrok-free.app` адрес в `WEBAPP_URL` в `.env`
и перезапустите сервер.

**Для постоянной работы:** задеплойте проект на любой Node.js-хостинг с
HTTPS из коробки — например Railway, Render, Fly.io или свой VPS с nginx +
Let's Encrypt. В `WEBAPP_URL` укажите итоговый адрес.

Если сервер будет постоянно онлайн, дополнительно задайте `WEBHOOK_URL`
(тот же публичный адрес) — тогда бот будет получать сообщения через
webhook вместо long polling, это надёжнее для прод-хостинга.

## 4. Запуск

```bash
npm start
```

В консоли появится «Сервер запущен на порту 3000» и «Бот работает через
long polling» (или webhook, если задан `WEBHOOK_URL`).

Откройте бота в Telegram, нажмите `/start` → «🚀 Открыть «Больше времени»».
Приложение также доступно через кнопку меню рядом с полем ввода сообщения.

## 5. Проверка без Telegram (по желанию)

Чтобы посмотреть интерфейс в обычном браузере на этапе вёрстки, поставьте
в `.env` `DEV_NO_AUTH=1` и откройте `http://localhost:3000` — API будет
работать от имени тестового пользователя. **Обязательно верните `0` перед
реальным запуском** — иначе кто угодно сможет обращаться к API в обход
проверки Telegram.

## Структура проекта

```
bolshe-vremeni/
├── src/
│   ├── server.js       # запуск Express + бота
│   ├── bot.js           # команды бота, кнопка Mini App

│   ├── auth.js            # проверка подписи Telegram initData
│   └── routes/orders.js    # REST API: категории, заказы
├── public/
│   ├── index.html        # разметка Mini App
│   ├── style.css          # стили (подстраиваются под тему Telegram)
│   └── app.js               # логика: вкладки, формы, запросы к API
├── .env.example
└── package.json
```

## Как это устроено

- Заказ проходит статусы `open → in_progress → done` (или `cancelled`).
- Автор заказа не может откликнуться на собственный заказ.
- Менять статус («Готово» / «Отменить») может только автор или исполнитель.
- Все запросы к API подписаны данными из `Telegram.WebApp.initData` и
  проверяются на сервере по алгоритму из [документации Telegram](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app) —
  это защищает от подмены пользователя.

## Возможные доработки

- Уведомления автору в личку бота, когда кто-то откликнулся на заказ
  (`bot.telegram.sendMessage`).
- Рейтинг и отзывы после выполнения заказа.
- Фильтр ленты по категории и городу/району.
- Загрузка фото поручения через `Telegram.WebApp` (`showPopup`,
  `sendData`) или отдельный эндпоинт загрузки файлов.
- Оплата через встроенные платежи Telegram (Bot API `sendInvoice`).
